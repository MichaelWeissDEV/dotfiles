# Pakete und Repositories

Das zentrale [dotfiles-Repository](https://github.com/MichaelWeissDEV/dotfiles) enthält Installer, Paketbau, Signierung und Dokumentation. Die Komponenten werden unabhängig entwickelt.

| Paket | Repository |
| --- | --- |
| `arch-dotfiles-core` | [dotfiles](https://github.com/MichaelWeissDEV/dotfiles) |
| `arch-dotfiles-oh-my-zsh` | [dotfiles](https://github.com/MichaelWeissDEV/dotfiles) |
| `arch-dotfiles-foot` | [foot](https://github.com/MichaelWeissDEV/foot-config) |
| `arch-dotfiles-fuzzel` | [fuzzel](https://github.com/MichaelWeissDEV/fuzzel-config) |
| `arch-dotfiles-ghostty` | [ghostty](https://github.com/MichaelWeissDEV/ghostty-config) |
| `arch-dotfiles-gtk-3.0` | [gtk-3.0](https://github.com/MichaelWeissDEV/gtk3-config) |
| `arch-dotfiles-gtk-4.0` | [gtk-4.0](https://github.com/MichaelWeissDEV/gtk4-config) |
| `arch-dotfiles-hypr` | [hypr](https://github.com/MichaelWeissDEV/hypr-config) |
| `arch-dotfiles-kitty` | [kitty](https://github.com/MichaelWeissDEV/kitty-config) |

| `arch-dotfiles` | [dotfiles](https://github.com/MichaelWeissDEV/dotfiles) |

Das Metapaket `arch-dotfiles` installiert die vollständige Umgebung; einzelne Pakete können unabhängig ausgewählt werden. Paketabhängigkeiten stehen in den jeweiligen PKGBUILDs. Siehe [Komponenten](components.md) für Konfigurationspfade und Anleitungen.
