# Tastenkombinationen

`Super` bezeichnet die Windows-Taste. Dies ist ein Einstieg; die vollständigen
Belegungen und versionsabhängigen Details stehen in den verlinkten Handbüchern.

| Taste | Funktion |
| --- | --- |
| Super + Leertaste | Anwendungsstarter |
| Super + Return | Terminal öffnen |
| Super + B | Browser öffnen |
| Super + E | Dateimanager öffnen |
| Super + L | Bildschirm sperren |
| Super + 1–9, 0 | Arbeitsfläche wechseln |
| Super + Shift + 1–9, 0 | Fenster auf Arbeitsfläche verschieben |
| Alt + Tab | Zum letzten Fenster wechseln |
| Super + Pfeiltaste | Fensterfokus verschieben |
| Druck | Bildschirmbereich aufnehmen |
| tmux Prefix, dann H | tmux Key Explorer öffnen |
| tmux Prefix, dann R | tmux-Konfiguration neu laden |

Alle Desktop-Belegungen: [Hyprland](hyprland.md). Für Anwendungen siehe
[Neovim](https://nvim-config.readthedocs.io/en/latest/),
[tmux](https://tmux-config.readthedocs.io/en/latest/),
[Vim](https://vim-config.readthedocs.io/en/latest/) und
[Kitty](https://kitty-config.readthedocs.io/en/latest/).
